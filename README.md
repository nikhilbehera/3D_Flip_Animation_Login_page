

## Run locally For Practice

1. Install Node.js if it is not installed.
2. Open this folder in VS Code.
3. Open the terminal in this folder.
4. Run:

   ```bash
   npm install
   npm run dev
   ```

5. Open the local URL Vite prints in your terminal (usually `http://localhost:5173`).

## Features

- Login and create-account forms
- 3D card flip between forms
- Neumorphic styling inspired by the reference screenshot
- Responsive layout
- Show/hide password controls
- Remember-me toggle
- Confirm-password validation
- Demo status messages for form submissions

## Important

This is a frontend-only demo. The login, account creation, and password-reset messages do not authenticate users or save accounts. Connect a backend or authentication provider before using it in production.
